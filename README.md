### 📌 Overview & SEO Summary

Welcome to the ultimate curated directory of **cloud integrated development environments (Cloud IDEs)**, **open-source Kubernetes-native IDEs**, **remote developer workspaces**, and **browser-based coding platforms**. The cloud IDE ecosystem has evolved rapidly: **Gitpod Classic sunset in October 2025 in favor of Ona**, **Google's Firebase Studio (Project IDX) announced discontinuation effective March 2027**, and **AWS Cloud9 has closed to new customers**. 

Whether you are searching for enterprise-grade commercial platforms (such as *GitHub Codespaces*, *Replit*, *StackBlitz*, and *Ona*), or self-hostable open-source solutions (like *code-server*, *Coder*, *Eclipse Theia*, *Eclipse Che*, and *JupyterLab*), this guide details exact features, pricing models, free tier quotas, and open-source star metrics.

## 🔓 Open-Source GitHub Projects

*Sorted by GitHub Star Count (Descending)* 🌟

- **[code-server](https://github.com/coder/code-server)** [![Stars](https://img.shields.io/github/stars/coder/code-server?style=social&color=white)](https://github.com/coder/code-server/stargazers) 💻  
  **VS Code in the browser on any remote server**, MIT licensed. Run VS Code on any Linux machine or cloud VM and access it securely through any web browser. Built-in terminal, extension marketplace support, low bandwidth overhead, and seamless SSH workflow integration. 🚀

- **[Coder](https://github.com/coder/coder)** [![Stars](https://img.shields.io/github/stars/coder/coder?style=social&color=white)](https://github.com/coder/coder/stargazers) 🛠️  
  **Self-hosted cloud development environments (CDEs)**, AGPL-3.0 licensed. Provision reproducible remote dev environments on your own cloud infrastructure (AWS, GCP, Azure, Kubernetes, bare-metal) using Terraform. Supports VS Code browser, JetBrains Gateway, SSH, and custom Dev Container templates. 🌐

- **[Eclipse Theia](https://github.com/eclipse-theia/theia)** [![Stars](https://img.shields.io/github/stars/eclipse-theia/theia?style=social&color=white)](https://github.com/eclipse-theia/theia/stargazers) 🏛️  
  **Extensible cloud & desktop IDE framework**, EPL-2.0 licensed. Multi-language vendor-neutral IDE platform supported by Eclipse Foundation, TypeFox, Red Hat, and Gitpod. Native support for VS Code extensions and LSP protocol in both web browser and desktop electron environments. 🎨

- **[JupyterLab](https://github.com/jupyterlab/jupyterlab)** [![Stars](https://img.shields.io/github/stars/jupyterlab/jupyterlab?style=social&color=white)](https://github.com/jupyterlab/jupyterlab/stargazers) 📊  
  **Extensible web-based environment for notebooks, code, and data**, BSD-3-Clause licensed. The primary web IDE for Python, R, Julia, and data science workflows. Features modular terminal integration, interactive charts, extension ecosystem, and rich output visualization. 🐍

- **[Gitpod](https://github.com/gitpod-io/gitpod)** [![Stars](https://img.shields.io/github/stars/gitpod-io/gitpod?style=social&color=white)](https://github.com/gitpod-io/gitpod/stargazers) 🦊  
  **Open-source automated developer environment platform**, AGPL-3.0 licensed. Automated, ephemeral dev environments built directly from GitHub, GitLab, or Bitbucket PRs with `.gitpod.yml` specifications and prebuild capabilities. ⚡

- **[Eclipse Che](https://github.com/eclipse-che/che)** [![Stars](https://img.shields.io/github/stars/eclipse-che/che?style=social&color=white)](https://github.com/eclipse-che/che/stargazers) ⚙️  
  **Kubernetes-native cloud IDE and developer workspace server**, EPL-2.0 licensed. The open-source upstream project behind Red Hat CodeReady Workspaces. Provides containerized workspaces managed in Kubernetes/OpenShift with Devfile standards and browser VS Code editing. 🏗️

- **[OpenVSCode Server](https://github.com/gitpod-io/openvscode-server)** [![Stars](https://img.shields.io/github/stars/gitpod-io/openvscode-server?style=social&color=white)](https://github.com/gitpod-io/openvscode-server/stargazers) 🔌  
  **Upstream VS Code web server distribution**, MIT licensed. Maintained project that compiles stock VS Code source into a headless server running directly in web browsers without desktop client installation. 📦

- **[Koding](https://github.com/koding/koding)** [![Stars](https://img.shields.io/github/stars/koding/koding?style=social&color=white)](https://github.com/koding/koding/stargazers) 🏢  
  **Self-hosted development environment for engineering teams**, AGPL-3.0 licensed. Enterprise self-hosted platform allowing teams to spin up cloud dev boxes, share live preview environments, and code collaboratively in browser terminals. 👥

- **[Codiad](https://github.com/Codiad/Codiad)** [![Stars](https://img.shields.io/github/stars/Codiad/Codiad?style=social&color=white)](https://github.com/Codiad/Codiad/stargazers) 📝  
  **Minimalist web-based IDE requiring simple PHP backend**, MIT licensed. Extremely lightweight web code editor designed for low-resource servers, shared PHP hosting, and fast remote file editing without complex node daemon setup. 💡

- **[Flux](https://github.com/RunOnFlux/flux)** [![Stars](https://img.shields.io/github/stars/RunOnFlux/flux?style=social&color=white)](https://github.com/RunOnFlux/flux/stargazers) 🌐  
  **Decentralized cloud infrastructure network**, MIT licensed. Enables hosting of web IDEs, containers, and web applications across a global, decentralized peer-to-peer cloud compute network. 🔗

- **[Codebox](https://github.com/FriendCode/codebox)** [![Stars](https://img.shields.io/github/stars/FriendCode/codebox?style=social&color=white)](https://github.com/FriendCode/codebox/stargazers) 🔧  
  **Open-source cloud IDE component for online/offline editing**, Apache-2.0 licensed. Modular web IDE engine featuring real-time collaborative editing, Git integration, and terminal output windows. 🛠️

- **[CollabVM](https://github.com/CollabVM/CollabVM)** [![Stars](https://img.shields.io/github/stars/CollabVM/CollabVM?style=social&color=white)](https://github.com/CollabVM/CollabVM/stargazers) 🎓  
  **Web-based virtual machine browser sharing platform**, AGPL-3.0 licensed. Designed for interactive OS education, system administration training, and browser-accessible remote virtual desktop instances. 💻

- **[CodeCafé](https://github.com/CodeCafe/CodeCafé)** [![Stars](https://img.shields.io/github/stars/CodeCafe/CodeCafé?style=social&color=white)](https://github.com/CodeCafe/CodeCafé/stargazers) ☕  
  **Hyper-collaborative real-time pair programming browser IDE**, MIT licensed. Zero-setup in-browser code editor built for instant code sharing, pair-programming interviews, and interactive web workshops. 🤝

- **[kodeWeave](https://github.com/michaelampr/kodeWeave)** [![Stars](https://img.shields.io/github/stars/michaelampr/kodeWeave?style=social&color=white)](https://github.com/michaelampr/kodeWeave/stargazers) ⚡  
  **Real-time HTML, CSS, and JS web playground**, MIT licensed. In-browser instant rendering playground for web prototyping, CSS styling experimentation, and offline web application drafting. 🎨

- **[OpenGravity](https://github.com/opengravity/opengravity)** [![Stars](https://img.shields.io/github/stars/opengravity/opengravity?style=social&color=white)](https://github.com/opengravity/opengravity/stargazers) 🤖  
  **Experimental AI-native cloud IDE UI with xterm.js & WebContainers**, MIT licensed. Lightweight BYOK (Bring Your Own Key) browser IDE equipped with interactive terminal capabilities and AI reasoning support. 🔬

- **[PythonAnywhere](https://github.com/pythonanywhere)** [![Stars](https://img.shields.io/github/stars/pythonanywhere?style=social&color=white)](https://github.com/pythonanywhere/stargazers) 🐍  
  **In-browser Python IDE, bash console, and web hosting platform**, Open-Source tools / Proprietary Service. Complete online Python dev environment with pre-installed PyPI packages, WSGI web servers, and scheduled cron jobs. 🌟

Contributions are warmly welcome! Follow these steps to submit new cloud IDE platforms or open-source development environment software:

1. 🍴 **Fork** the repository.
2. 📝 **Add/edit** entries in `README.md` maintaining exact table and list structure.
3. 🔗 Include official project title, GitHub repository link, star badge, exact price/limit details, and a clear description.
4. 🚀 Submit a **Pull Request** with a descriptive summary of your contribution.

## ⚠️ Disclaimer

- This is a **community-curated list** — not exhaustive and not an endorsement. ℹ️
- **The cloud IDE market continues to shift**: AWS Cloud9 is closed to new users, Gitpod Classic sunset in Oct 2025, Firebase Studio (Project IDX) shuts down March 22, 2027, and Codeanywhere is decommissioned. Evaluate platform longevity prior to production deployment.
- **GitHub Codespaces billing is in core-hours**: 120 core-hours/month equates to ~60 hours of active 2-core runtime. Default idle timeout is 30 minutes.
- **Open-source self-hosted solutions** (Coder, Eclipse Che, code-server) require initial infrastructure setup, domain SSL configuration, and ongoing container management.
